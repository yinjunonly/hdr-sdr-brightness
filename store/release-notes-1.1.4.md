# Microsoft Store 1.1.4 release notes

## en-US

Removes the custom fast-startup scheduled task and uses only the standard Windows startup mechanism, preventing an incorrect Microsoft Defender persistence alert. Also includes the high-DPI clarity and first-run SDR brightness improvements from 1.1.3.

## zh-CN

移除自定义快速启动计划任务，仅使用 Windows 标准开机启动机制，避免 Microsoft Defender 错误报告持久化行为；同时包含 1.1.3 的高 DPI 清晰度和首次 SDR 亮度改进。

## zh-Hant

移除自訂快速啟動排程工作，僅使用 Windows 標準開機啟動機制，避免 Microsoft Defender 錯誤回報持久性行為；同時包含 1.1.3 的高 DPI 清晰度與首次 SDR 亮度改進。

## de-DE

Entfernt die benutzerdefinierte Aufgabe für den Schnellstart und verwendet nur noch den standardmäßigen Windows-Autostart. Dadurch wird eine fehlerhafte Microsoft-Defender-Warnung vor Persistenz vermieden. Enthält außerdem die Verbesserungen aus 1.1.3 für High-DPI-Darstellung und die anfängliche SDR-Helligkeit.

## ja-JP

独自の高速スタートアップ用スケジュール タスクを削除し、Windows 標準のスタートアップ機能のみを使用することで、Microsoft Defender による永続化動作の誤検出を防ぎます。1.1.3 の高 DPI 表示と初回 SDR 輝度の改善も含まれます。

## ko-KR

사용자 지정 빠른 시작 예약 작업을 제거하고 표준 Windows 시작 기능만 사용하여 Microsoft Defender의 지속성 동작 오탐을 방지합니다. 1.1.3의 고 DPI 선명도 및 최초 실행 SDR 밝기 개선 사항도 포함됩니다.

## ru-RU

Удалена пользовательская задача быстрого запуска; теперь используется только стандартный механизм автозапуска Windows, что предотвращает ложное предупреждение Microsoft Defender о закреплении в системе. Также включены улучшения версии 1.1.3 для дисплеев с высоким DPI и начальной яркости SDR.
