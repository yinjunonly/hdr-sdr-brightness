# Microsoft Store 1.1.3 release notes

## en-US

Improves clarity on high-DPI and 4K displays with Per-Monitor V2 scaling. On first run, Day and Night presets now use your current Windows SDR content brightness, avoiding an unexpected brightness change. Existing presets remain unchanged.

## zh-CN

通过 Per-Monitor V2 缩放修复高 DPI 和 4K 显示器上的界面发糊。首次运行时，白天和夜间预设会采用 Windows 当前 SDR 内容亮度，避免启动后突然改变亮度；已有预设保持不变。

## zh-Hant

透過 Per-Monitor V2 縮放修正高 DPI 與 4K 顯示器上的介面模糊。首次執行時，白天與夜間預設會採用 Windows 目前的 SDR 內容亮度，避免啟動後突然改變亮度；現有預設保持不變。

## de-DE

Verbessert die Darstellung auf High-DPI- und 4K-Bildschirmen durch Per-Monitor-V2-Skalierung. Beim ersten Start verwenden die Tag- und Nacht-Voreinstellungen nun die aktuelle Windows-Helligkeit für SDR-Inhalte. Vorhandene Voreinstellungen bleiben unverändert.

## ja-JP

Per-Monitor V2 スケーリングにより、高 DPI／4K ディスプレイでのぼやけを修正しました。初回起動時は、昼間と夜間のプリセットに Windows の現在の SDR コンテンツの明るさを使用し、突然明るさが変わるのを防ぎます。既存の設定は変更されません。

## ko-KR

Per-Monitor V2 배율을 적용해 고 DPI 및 4K 디스플레이에서 흐릿하게 보이던 문제를 수정했습니다. 처음 실행할 때 주간 및 야간 사전 설정은 현재 Windows SDR 콘텐츠 밝기를 사용하므로 밝기가 갑자기 바뀌지 않습니다. 기존 설정은 그대로 유지됩니다.

## ru-RU

Улучшена четкость интерфейса на дисплеях с высоким DPI и 4K благодаря масштабированию Per-Monitor V2. При первом запуске дневной и ночной профили используют текущую яркость SDR-содержимого Windows, предотвращая неожиданное изменение яркости. Существующие настройки сохраняются.
