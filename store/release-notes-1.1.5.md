# 1.1.5

## English

- Fixed an issue where a running instance could miss Windows Night Light changes.
- Follow Windows now tracks the current Night Light state for sunset-to-sunrise schedules, custom hours, and manual enable or disable.
- Added a periodic fallback check so a missed Windows notification is recovered within 15 seconds.

## 简体中文

- 修复软件运行期间可能无法响应 Windows 夜间模式切换的问题。
- “跟随系统”现在会跟随 Windows 当前的夜间模式状态，支持日落到日出、自定义小时以及手动启用或禁用。
- 增加周期兜底检查；即使错过 Windows 通知，也会在 15 秒内重新同步。
