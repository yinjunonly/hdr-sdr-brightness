# Screenshot Plan

Recommended Store screenshots. Capture at 1366 x 768 or larger with clear text and no personal information visible.

Screenshots are organized by Store listing language:

```text
store\screenshots\en-US
store\screenshots\zh-CN
```

## Required Minimum

```text
At least one screenshot of the main settings window.
```

## Recommended Set

1. Settings window, light theme

```text
Show the app title, Day/Night SDR brightness sliders, switching mode, and SDR/HDR preview.
Use neutral values such as Day 25% and Night 10%.
```

2. Settings window, dark theme

```text
Show the same core controls in dark mode to demonstrate theme support.
Avoid overlapping tray menus or system notifications.
```

3. Tray menu

```text
Show Apply now, Settings, Start with Windows, Display settings, Night Light settings, and Exit.
For the Store build, confirm Support author is not present.
```

4. HDR preview and controls close-up

```text
Focus on the live SDR/HDR preview area and brightness controls.
This helps customers understand the app's purpose quickly.
```

5. Startup settings evidence, optional

```text
Show Windows Settings > Apps > Startup with the app visible.
Use this only for certification/support evidence, not necessarily as a public Store screenshot.
```

## Capture Checklist

```text
Use the Store build, not the desktop ZIP build.
Use screenshots in the same language as the Partner Center listing.
Confirm support/donation/supporter-code UI is hidden.
When automating screenshots, move the natural app window on screen without resizing it. Do not force the settings window to a smaller fixed pixel size; high-DPI systems will compress the custom layout.
Do not add decorative shadows, frames, device mockups, or marketing text over the screenshots.
Confirm app name in title bar is HDR SDR Brightness Assistant 设置 / Settings.
Confirm the main in-app title remains localized and short.
Confirm no email, account, personal path, or unrelated app is visible.
Confirm Windows scaling does not blur text excessively.
Confirm screenshots match the language of the Store listing where possible.
```
