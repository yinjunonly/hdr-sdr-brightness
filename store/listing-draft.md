## en-US

Short description:

```text
Keep Windows SDR content brightness predictable when HDR is enabled. Set separate day and night SDR brightness levels, follow Windows Night Light, and run quietly from the system tray.
```

Description:

```text
HDR SDR Brightness Assistant is a lightweight Windows tray utility for keeping SDR content brightness comfortable and predictable while Windows HDR is enabled.

It is built for OLED, QD-OLED, MiniLED, HDR monitors, HDR TVs, and HDR laptop panels where regular SDR apps may look too bright, too dim, or washed out after HDR is turned on.

Set separate day and night SDR content brightness levels, choose whether to follow Windows Night Light, and let the app quietly restore your preferred SDR brightness when a manual change is detected.

The app stays out of the way in the system tray, supports tray-only startup, follows the Windows light or dark app theme, and includes a live SDR/HDR preview in the settings window.

HDR SDR Brightness Assistant is a paid Microsoft Store app with a time-limited free trial. It has no in-app purchases, donation prompts, subscriptions, or unlock codes. It does not install drivers, services, browser components, or secondary software. It stores settings locally for the current Windows user and does not require an account.
```

```text
Runs quietly from the system tray
```

Description:

```text
HDR SDR 亮度助手是一个轻量的 Windows 托盘工具，用来在开启 Windows HDR 时，让 SDR 内容亮度保持稳定、舒适、可预期。

它适合 OLED、QD-OLED、MiniLED、HDR 显示器、HDR 电视和支持 HDR 的笔记本屏幕。开启 HDR 后，如果普通 SDR 软件看起来过亮、过暗或发灰，可以用它自动切换和修正 SDR 内容亮度。

你可以分别设置白天和夜间 SDR 内容亮度，选择是否跟随 Windows 夜间模式，也可以使用内置默认时段。检测到手动修改 SDR 内容亮度后，应用可以自动恢复到配置值。

应用会安静常驻系统托盘，支持经用户开启后的托盘模式自启动，自动跟随 Windows 浅色/深色应用主题，并在设置页提供 SDR/HDR 实时预览。

HDR SDR 亮度助手是 Microsoft Store 付费应用，并提供限时免费试用。它不包含应用内购买、捐赠提示、订阅或解锁码，不安装驱动、服务、浏览器组件或附加软件。配置仅保存在当前 Windows 用户本地，不需要账户登录。
```
