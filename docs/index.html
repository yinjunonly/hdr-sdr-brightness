FAQ

Does it change game HDR?

No. It targets Windows SDR content brightness while HDR is enabled, so HDR games and videos can stay HDR.

Does it need admin rights?

No. The app runs as a normal user app from the tray and does not install a driver or Windows service.

Does it collect analytics?

No. Settings stay local. The app does not require an account and does not include telemetry or third-party tracking.

Which languages are supported?

Auto, Simplified Chinese, Traditional Chinese, English, Korean, Japanese, Russian, and German.

Try it from Microsoft Store.

Install the Store version to use the full-feature trial, receive updates through Microsoft Store, and keep setup simple.
