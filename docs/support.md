# HDR SDR Brightness Assistant Support

HDR SDR Brightness Assistant is a Windows desktop utility for adjusting Windows SDR content brightness while HDR is enabled.

## Quick Checks

If brightness changes do not appear to work:

1. Make sure Windows HDR is enabled for the target display.
2. Open Windows Settings > System > Display and confirm the display supports HDR.
3. Open HDR SDR Brightness Assistant from the system tray.
4. Adjust Day or Night SDR brightness and click Apply now.
5. If the display still looks incorrect, run Microsoft's Windows HDR Calibration app.

## Startup

The Microsoft Store version uses the Windows packaged-app startup task. Startup is disabled by default. To start the app with Windows, enable Start with Windows in the app or enable the app in Windows Settings > Apps > Startup.

If Windows reports that startup is disabled by system policy, the app respects that setting.

## Store Version

## Privacy

# HDR SDR 亮度助手支持

HDR SDR 亮度助手是一个 Windows 桌面工具，用来在开启 Windows HDR 时调整 Windows SDR 内容亮度。

## 快速检查

如果亮度调整看起来没有生效：

1. 确认目标显示器已经开启 Windows HDR。
2. 打开 Windows 设置 > 系统 > 屏幕，确认该显示器支持 HDR。
3. 从系统托盘打开 HDR SDR 亮度助手。
4. 调整白天或夜间 SDR 亮度，然后点击“立即应用”。
5. 如果显示效果仍然异常，建议运行微软的 Windows HDR Calibration 应用进行 HDR 校准。

## 自启动

Microsoft Store 版本使用 Windows 打包应用自启动任务。自启动默认关闭。若要开机启动，请在应用中开启“开机自启”，或在 Windows 设置 > 应用 > 启动 中启用本应用。

如果 Windows 提示自启动被系统策略禁用，应用会遵守该系统设置。
