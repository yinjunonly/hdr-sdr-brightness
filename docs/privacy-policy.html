Privacy Policy

Effective date: 2026-05-17

HDR SDR Brightness Assistant is a Windows desktop utility that helps adjust Windows SDR content brightness while HDR is enabled.

Data Collection

HDR SDR Brightness Assistant does not collect, transmit, sell, rent, or share personal data.

The app does not require an account, does not include telemetry, does not use analytics SDKs, and does not send display information, settings, supporter codes, device identifiers, crash reports, or usage data to the developer.

Local Settings

The app stores configuration locally on the current Windows user profile. This may include brightness preferences, schedule settings, language selection, startup preference, and other app settings. These settings remain on the user's device and are not transmitted by the app.

Microsoft Store Purchase Data

If the app is acquired through Microsoft Store, purchase and licensing information is handled by Microsoft Store according to Microsoft's own terms and privacy policies. HDR SDR Brightness Assistant does not receive or process payment card information.

Startup Behavior

The Microsoft Store version uses the Windows packaged-app startup task mechanism. Startup is disabled by default and is enabled only when the user turns on Start with Windows in the app or through Windows Settings. Users can disable startup at any time.

Network Access and Third Parties

HDR SDR Brightness Assistant does not need network access for its core functionality. The Microsoft Store version does not include donation links, in-app purchases, subscriptions, supporter-code entry, advertising, or third-party tracking.

Children's Privacy

HDR SDR Brightness Assistant is a general-purpose utility and is not directed to children. The app does not knowingly collect personal data from children.

Changes and Contact

This privacy policy may be updated when the app changes. The latest version will be available at this page.

For support or privacy questions, contact yinjunonly@outlook.com.

隐私政策

生效日期：2026-05-17

HDR SDR 亮度助手是一个 Windows 桌面工具，用来在开启 Windows HDR 时调整 Windows SDR 内容亮度。

数据收集

HDR SDR 亮度助手不会收集、传输、出售、出租或共享个人数据。

应用不需要账户登录，不包含遥测，不使用分析 SDK，也不会向开发者发送显示器信息、设置、支持者码、设备标识符、崩溃报告或使用数据。

本地设置

应用会在当前 Windows 用户配置中保存本地设置。这些设置可能包括亮度偏好、时段设置、语言选择、自启动偏好和其他应用配置。这些设置保留在用户设备本地，应用不会主动传输这些设置。

Microsoft Store 购买数据

如果应用通过 Microsoft Store 获取，购买和许可信息由 Microsoft Store 按照微软自己的条款和隐私政策处理。HDR SDR 亮度助手不会接收或处理银行卡等付款信息。

自启动行为

Microsoft Store 版本使用 Windows 打包应用自启动任务机制。自启动默认关闭，只有当用户在应用内开启“开机自启”或在 Windows 设置中启用时才会生效。用户可以随时关闭自启动。

网络访问和第三方服务

HDR SDR 亮度助手的核心功能不需要网络访问。Microsoft Store 版本不包含捐赠链接、应用内购买、订阅、支持者码入口、广告或第三方跟踪。

儿童隐私

HDR SDR 亮度助手是通用工具软件，并非面向儿童。应用不会有意收集儿童个人数据。

变更和联系方式

当应用发生变化时，本隐私政策可能会更新。最新版本会发布在本页面。如需支持或有隐私相关问题，请联系 yinjunonly@outlook.com。
